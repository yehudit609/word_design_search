# WordFormatSearch – חיפוש עיצוב ל-Word

תוסף ל-Word Desktop (Windows) לחיפוש לפי טקסט, עיצוב, או טקסט + עיצוב.
כל תוצאה היא `Word.Range` אמיתי, ונבחרת במסמך באמצעות `range.select()`.

## התקנה

דרישות: Windows, Word Desktop (Microsoft 365 / 2019 ומעלה), Node.js LTS (18+).

1. חלצו את התיקייה אל `C:\WordFormatSearch`.
2. פתחו PowerShell בתיקייה והריצו:
   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   .\install.ps1
   ```
   בפעם הראשונה Windows ישאל אם לסמוך על "Developer CA for Microsoft Office Add-ins" – יש לאשר.
3. סגרו את Word לחלוטין ופתחו מחדש.
4. `בית → תוספות → Shared Folder → חיפוש עיצוב`.
   לאחר הטעינה יופיע כפתור **חיפוש עיצוב** בכרטיסיית "בית".

השרת עולה אוטומטית בכל כניסה ל-Windows (משימה מתוזמנת `WordFormatSearch Server`, ללא חלון).
אם אין הרשאה ליצור משימה מתוזמנת, הסקריפט יוצר קיצור דרך בתיקיית Startup במקום.

הסרה: `.\uninstall.ps1` (לא מוחק את קבצי הפרויקט).

## מבנה

```
manifest.xml        הגדרת התוסף (כולל כפתור בסרגל)
server.js           שרת HTTPS מקומי – 127.0.0.1:3000 בלבד, מגיש רק src/ ו-assets/
start-server.vbs    מפעיל את השרת ללא חלון
install.ps1         התקנה + משימה מתוזמנת
uninstall.ps1       הסרת המשימה
src/taskpane.*      ממשק ולוגיקה
assets/             אייקונים 16/32/80
tests/              בדיקות + מסמך בדיקה (test-document.docx)
logs/server.log     נוצר בזמן ריצה
```

## החלטות מימוש עיקריות

- **ניווט**: אובייקטי Office.js תקפים רק בתוך `Word.run`, לכן לכל תוצאה נשמר "מאתר" –
  אינדקס בחיפוש Word (חיפוש טקסט), או מספר פסקה + מספר מילה (חיפוש עיצוב).
  בכל מעבר ה-Range מאותר מחדש, נבדק שהטקסט שלו זהה, ונבחר. אם המסמך השתנה מוצגת הודעה לרענן.
- **ביצועים**: חיפוש עיצוב רץ במנות של 150 פסקאות; בכל מנה `sync` אחד לפירוק ולטעינת העיצוב
  (ועוד אחד רק למילים עם פיסוק בקצוות). נטענים רק מאפייני העיצוב שסומנו. ניתן לבטל סריקה ארוכה.
- **מילה**: `getTextRanges()` עם המפרידים שבמפרט, מלבד גרש/גרשיים/מרכאות – כך `עו״ד` ו-`צ׳יפס`
  נשארות מילה אחת, ומרכאות בקצוות מוסרות. נוסף המקף העברי `־`. מילה עם פיסוק בקצה (`שלום,`)
  נבחרת ונבדקת ללא הפיסוק.
- **עיצוב מעורב**: מילה שחלקה מודגש אינה נחשבת "מודגשת". ב"קח עיצוב מהבחירה" מאפיין מעורב
  לא מסומן ומוצג בהודעה. רווח שנבחר בלחיצה כפולה מתעלם.
- **"מצא מילים בעיצוב דומה"**: משווה לפי המאפיינים המסומנים. אם אף מאפיין אינו מסומן – משווה לפי
  כל המאפיינים האחידים של הבחירה. שדה הטקסט מתעלם בפעולה זו.
- **מודגש/נטוי** כוללים בחירה "כן / לא", כדי שאפשר יהיה לחפש גם "לא מודגש".
- **Enter**: אם הקלט השתנה מאז החיפוש האחרון – מריץ חיפוש; אחרת עובר לתוצאה הבאה.
- `Cache-Control: no-store` בשרת – לאחר עדכון קבצים מספיק לסגור ולפתוח את החלונית.
- התעודה המקומית מותקנת ל-365 יום; הרצה חוזרת של `install.ps1` מחדשת אותה כשנותרו פחות מ-30 יום.

## מגבלות ידועות

- נסרק גוף המסמך בלבד (כולל טבלאות) – לא כותרות עליונות/תחתונות, תיבות טקסט והערות שוליים.
- טקסט חיפוש עד 255 תווים (מגבלת Word). עד 10,000 תוצאות.
- ההרשאה במניפסט היא `ReadWriteDocument` כדי ש-`select()` יעבוד בוודאות; הקוד אינו כותב למסמך.
- Shared Folder הוא מנגנון sideload לבדיקות, לא להפצה ארגונית (ראו סעיף 25 במפרט).

## בדיקות

```
node tests/logic.test.js     # לוגיקת התאמה ופירוק מילים
node tests/ui.test.js        # ממשק מקצה לקצה מול Word מדומה (דורש playwright)
```

לבדיקה ידנית ב-Word פתחו את `tests/test-document.docx` – הוא מכסה את רשימת הבדיקות שבסעיף 38
(עברית/אנגלית, פיסוק, גרשיים, מקפים, צבעים, הדגשות, גדלים, עיצוב מעורב, טבלה, מסמך ארוך).
